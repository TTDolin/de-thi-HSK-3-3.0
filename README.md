# Đề thi thử HSK 3 3.0 — Tiếng Trung Dolin

Trang tĩnh (HTML/CSS/JS thuần) gồm 2 đề 《中文水平考试 HSK 3.0（三级）全真模拟试卷》.

- `index.html` — giao diện và chấm điểm
- `data.js` — câu hỏi, đáp án, lời thoại, mốc thời gian file nghe, cách tính điểm (`SCORE`)
- `audio/` — file nghe đề 1, đề 2 · `pic/` — hình cắt từ đề · `logo.png`

Lưu ý: file nghe gốc của đề 1 bị thiếu câu 18–30; các câu đó được tạo bằng giọng đọc máy theo lời thoại, xem ghi chú `audioNote` trong `data.js`.
